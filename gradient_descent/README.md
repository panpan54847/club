# 梯度下降 - 线性回归预测房价

## 项目简介

梯度下降是最基础的优化算法，通过沿梯度反方向逐步更新参数来最小化损失函数。

本项目用梯度下降实现 **一元线性回归**：
- 根据房屋面积预测房价
- 拟合一条直线 `y = wx + b`
- 最小化均方误差（MSE）

## 核心概念

| 概念 | 说明 |
|------|------|
| 模型 | `y = wx + b`（w斜率, b截距）|
| 损失函数 | `MSE = (1/n) * Σ(y_pred - y_true)²` |
| 梯度 | 对 w 和 b 分别求偏导 |
| 学习率 | 每步更新的步长（太大不稳定，太小收敛慢）|

## 算法流程

1. 初始化参数 `w` 和 `b`（随机或设为0）
2. 计算预测值：`y_pred = wx + b`
3. 计算损失：`MSE = (1/n) * Σ(y_pred - y_true)²`
4. 计算梯度：
   - `∂L/∂w = (2/n) * Σ((y_pred - y_true) * x)`
   - `∂L/∂b = (2/n) * Σ(y_pred - y_true)`
5. 更新参数：
   - `w = w - lr * ∂L/∂w`
   - `b = b - lr * ∂L/∂b`
6. 重复步骤 2-5，直到损失收敛

> **注意**：学习率（lr）的选择很关键。本项目面积值在 30~200 范围，
> 梯度较大，如果学习率太大（如 0.01）会导致梯度爆炸。
> 因此使用较小的学习率（0.000001）配合更多迭代轮数（10000）来保证收敛。

# 模拟退火算法 - 快递配送路线规划（TSP）

## 项目简介

模拟退火算法受物理学中金属退火过程启发，通过"高温时大胆探索、低温时精细收敛"的策略，
有效跳出局部最优解，适用于组合优化问题。

本项目用模拟退火解决 **旅行商问题（TSP）**：
- 假设快递员要给 N 个地点送快递
- 每个地点只去一次，最终回到起点
- 目标：找到总距离最短的路线

## 核心概念

| 概念 | 对应 TSP |
|------|----------|
| 能量/成本 | 路线总距离 |
| 温度 | 接受劣解的概率（高温=大胆，低温=保守）|
| 冷却 | 温度逐渐下降 |
| 邻域解 | 交换路线中两个城市的位置 |

## 算法流程

1. 随机生成一条初始路线
2. 计算当前总距离（能量）
3. 随机交换两个城市，得到新路线
4. 计算新距离：
   - 如果更短 → 直接接受
   - 如果更长 → 以 `exp(-ΔE/T)` 的概率接受（避免卡在局部最优）
5. 温度降低，重复步骤 3-4
6. 温度足够低时，输出最优路线

## 运行方式

```bash
python main.py
```
